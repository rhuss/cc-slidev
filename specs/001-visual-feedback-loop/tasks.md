# Tasks: Visual Balance Pass for Rendered Slides

**Input**: Design documents from `specs/001-visual-feedback-loop/` (plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md)

**Tests**: Included. The plan defines `node --test` unit suites and an opt-in render integration test; success criteria SC-003, SC-005, SC-007, SC-008, SC-009 get automated checks.

**Paths**: Plugin code under `slidev/`, tests under `tests/balance/`. Commands reference plugin files through `${CLAUDE_PLUGIN_ROOT}`; scripts resolve siblings relative to their own location.

**Global constraints** (apply to every task): FR-004 (never modify the deck's `package.json` or lockfile, no MCP server); FR-014 (automatic edits only touch frontmatter `layout`, `zoom`, `class` and column slot markers; zoom between 1.0 and 1.5); FR-018 (no applied fix exceeds 6 elements or 50 words of body text); no em or en dashes in new prose.
