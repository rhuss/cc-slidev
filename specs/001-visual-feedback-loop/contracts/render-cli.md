# Contract: `slidev/scripts/balance/render-slides.sh`

All subcommands run with the deck directory as CWD (or `--deck <dir>`). Exit codes: `0` ok, `1` failure, `2` usage error, `3` render environment unavailable (with setup hint on stderr).

| Subcommand | Behavior |
|---|---|
| `ensure` | Install `playwright-core@1.64.1` into `${XDG_CACHE_HOME:-$HOME/.cache}/cc-slidev/render` if missing (prints `NOTICE: installing render tooling (one-time)`); install Chromium revision via `playwright-core install chromium` only if the shared cache lacks it. Prints `RENDER_READY <cache-dir>`. Offline/failed → exit 3 with the manual command. node, npm or jq missing → exit 3. |
| `ensure --check` | Installs nothing. Prints `RENDER_READY <cache-dir>` or `INSTALL_NEEDED <what>` (`playwright-core <pin> and Chromium (one-time)` or `Chromium (one-time)`), exit 0 either way, so the command can announce a long first install (FR-006). |
| `server start [--preview]` | Reuse or start the main (or preview) dev server; prints `SERVER <role> port=<p> owned=<bool>`. |
| `server stop` | Stop servers with `owned: true` (`SERVER <role> stopped port=<p>`), forget reused ones without stopping them (`SERVER <role> released port=<p>`), set their registry entries to null; remove `.balance-preview.md`. A started server logs to `exports/balance/server-<role>.log`. |
| `render --run <dir> --round <n> [--slides <range>]` | Render slides in last click state; writes `<dir>/round-<n>/slide-NN.png` and `<dir>/round-<n>/metrics.json` (array of SlideMetrics with `flags` filled). Per-slide render failures go into `render_error`, exit stays 0. `--round` is 0 or a positive integer; `--round 0` is the baseline of slides the pass changes before round 1 (palette, placed images), so the report has their before image. An out-of-range `--slides` exits 2 and names the valid range. |
| `preview --run <dir> --name <name> --slide-file <md> [--split]` | Writes `.balance-preview.md` (one merged frontmatter block plus the candidate body, so it is slide 1; see research R6), adds it to the deck's `.gitignore` when one exists, ensures the preview server, renders it to `<dir>/previews/<name>.png` (a multi-slide candidate: `<name>-1.png`, `<name>-2.png`, ...). Stdout is only one JSON preview-metrics line per slide (SlideMetrics plus `preview: {name, index, count}`). `--split` requires at least two slides in the file (exit 2 otherwise). |
| `contact-sheet --run <dir> --round <n>` | Writes `<dir>/contact-sheet.png` (grid of the latest PNG per slide). |
| `rhythm --run <dir>` | Prints JSON rhythm observations from the latest metrics per slide. |

Stdout lines prefixed `SLIDE`, `SERVER`, `RENDER_READY`, `INSTALL_NEEDED`, `NOTICE`, `WARNING`; JSON payloads only where stated.

## Helper scripts

- `generate-image.sh --route <r> [--model <m>] --prompt-file <f> --aspect <w:h> --out <file>`: exit 0 + `IMAGE <file>`, exit 3 route unavailable (`UNAVAILABLE <reason>`), exit 1 generation failed (`FAILED <reason>`). `generate-image.sh --route <r> --check`: exit 0 + `AVAILABLE <route>`, or exit 3 + `UNAVAILABLE <reason>`.
- `fit-image.sh --in <file> --aspect <w:h> [--out <file>]`: crop with ImageMagick if present; prints `FITTED magick` or `FITTED css` (caller then sets `object-fit: cover`).
- `box-styles.mjs generate --deck <dir> [--config <md>] [--palette <default|okabe-ito>] [--out <css> [--scoped-safe]] [--check]`: reads `balance.boxes` from the config (`--config`, default `<deck>/presentation-config.md`), or takes the roles from the `--palette` preset, validates (contrast, hue rules), writes `styles/balance-boxes.css`, ensures the import in `styles/index.css`, prints `CHANGED` or `UNCHANGED`. `--out` writes the CSS to that file instead and leaves `styles/index.css` alone; `--scoped-safe` (only with `--out`) wraps every selector in `:global(...)` for inline slide `<style>`. `--check` writes nothing and prints what a run without it would print. Exit 1 on validation failure.
- `box-styles.mjs set --deck <dir> --palette <default|okabe-ito|custom|harvested> [--roles main=#hex,risk=#hex,context=#hex,takeaway=#hex] [--config <md>]`: validates and writes `balance.boxes` into the config frontmatter (creating the file or the frontmatter when missing), prints `WROTE <path>`; exit 1 stores nothing. `box-styles.mjs harvest --deck <dir>` prints `{"colors": [{name, hex, count}]}` found in existing `bg-<color>-<shade>/<n>` classes.
- `apply-auto-fix.mjs --file <src> --start <l> --end <l> --set layout=<v> [--set zoom=<v>] [--set class=<v>] [--slots <spec>] [--approved --set image=<path> [--set backgroundSize=<v>]]`: edits only frontmatter keys and column slot markers of one slide; `--approved` (only after the presenter accepted an image fix) allows `image` and `backgroundSize`. Slot specs: `<slot>=<n>`, `<slot>-before:<n>`, `move-<slot>:<n>`, `remove-<slot>` (`<slot>` is `left` or `right`). Aborts with exit 1 if the body text or its order would change or a slot marker would land inside an open HTML or component block; exit 2 for a disallowed key, zoom out of bounds or a bad slot spec. On success prints one JSON line `{before, after, end_after, line_delta}` (`before` is the revert record).
- `slide-map.mjs build --deck <dir> [--entry <file>] --out <json>`: writes the SlideMap, prints `SLIDEMAP <file> slides=<n> hidden=<h>`; exit 1 on a missing or circular `src:` import. `slide-map.mjs renumber --map <json> --after <current_no> --delta <+n|-n>`: shifts `current_no` after splits and merges. `slide-map.mjs shift-lines --map <json> --file <source_file> --after-line <l> --delta <+n|-n>`: shifts line ranges (and `frontmatter_overrides` blocks) after an edit that changed the line count. `slide-map.mjs refresh-layout --map <json> --deck <dir> [--entry <file>]`: recomputes every live slide's effective `layout` from the deck, prints `LAYOUT <start_no> <old> -> <new>` per change and `LAYOUTS changed=<n>`; exit 1 (map unchanged) when the map no longer matches the deck.
- `side-by-side.mjs --left <png> --right <png> --out <png>`: composes current and preview into one image.
- `report.mjs --run <dir>`: builds `report.md` from metrics, verdicts and `decisions.jsonl`.
- `count-limits.mjs --file <slide.md>`: prints `{elements, words}` per the design-constraints counting rules (boxes included).
